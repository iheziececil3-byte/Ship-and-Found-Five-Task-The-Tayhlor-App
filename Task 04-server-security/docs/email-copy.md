# Email Copy Notes

## Where the copy came from
The verification and welcome email copy was generated by the AI agent as part of the scaffolding process. It uses standard transactional phrasing ("Welcome to Tayhlor!", "Your verification code is...", "This code expires in 7 minutes"). The HTML template was built using our Task 1 design tokens (navy blue `#101B2D`, Manrope font) to ensure brand consistency.

## What I would change for real customers
If this were going to real customers, I would change the tone to match the bespoke, premium feel of the tailoring business. Instead of a generic "Welcome to Tayhlor," I would write something more personal, like: "Thank you for choosing Tayhlor. We look forward to crafting your perfect fit."
